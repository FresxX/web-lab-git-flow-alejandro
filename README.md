# Git Flow Lab

Version: 1.0.0

A simple front-end project developed to practice Git Flow.

## Features

- Navigation header
- Responsive design
- Dark mode toggle
- Improved text contrast for accessibility
- Minified CSS for production

## Technologies

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## How to run

1. Clone the repository.
2. Open index.html in a web browser.
3. Click the Dark mode button to switch themes.

## Git Flow

This project follows a Git Flow branching strategy:

- main: Production-ready code
- develop: Integration branch
- feature/*: New features
- hotfix/*: Critical fixes
- release/*: Release preparation
